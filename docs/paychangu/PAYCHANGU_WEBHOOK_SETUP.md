## 📋 Step-by-Step Configuration

### **STEP 1: Configure Test Webhook (Development)**

You're currently on the Test mode settings page. Here's what to fill in:

#### 1.1 Test Webhook URL

**Local Development:**
```
http://localhost:5000/api/payments/webhook/paychangu
```

**If Using ngrok for Testing:**
```bash
# Install ngrok if you don't have it
# Download from: https://ngrok.com/download

# Start ngrok tunnel to your backend
ngrok http 5000

# You'll get a URL like: https://abc123.ngrok.io
# Use: https://abc123.ngrok.io/api/payments/webhook/paychangu
```

**Production:**
```
https://autotek.mw/api/payments/webhook/paychangu
```

#### 1.2 Test Webhook Secret

**Important:** The webhook secret is usually **generated by PayChangu**, not by you.

**Where to find it:**
1. Look for a "Generate" or "Show" button near the "Test Webhook secret" field
2. Or check if there's a separate "Webhook Secret" field above (might be hidden with dots like the API keys)
3. If you don't see it, you may need to click "Copy" on "Test Secret key" at the top

**If you can generate it:**
- Click any "Generate" button
- Copy the secret immediately
- Save it securely

**If it's auto-generated:**
- It might already be there (hidden with dots)
- Click "Copy" to get the value
- Or click "Show" if available

#### 1.3 Enable Notifications

Toggle ON: **"Receive Webhook Notifications"**

#### 1.4 Save Configuration

Click the **"Save"** button at the bottom

---

### **STEP 2: Add Webhook Secret to .env**

Once you have the webhook secret from PayChangu:

```bash
# In backend/.env, update line 25:
PAYCHANGU_WEBHOOK_SECRET=your_webhook_secret_from_dashboard
```

**Example:**
```bash
# If your secret is: whsec_abc123xyz789
PAYCHANGU_WEBHOOK_SECRET=whsec_abc123xyz789
```

---

### **STEP 3: Test Webhook**

#### 3.1 Using PayChangu Dashboard

1. Click the **"Test Webhook"** button (top right of the screenshot)
2. PayChangu will send a test webhook to your URL
3. Check your backend logs for:
   ```
   [timestamp] info: [PayChangu] Webhook received
   [timestamp] info: PayChangu webhook: Signature verified successfully
   ```

#### 3.2 Manual Test with curl

```bash
# Start your backend
cd backend && npm run dev

# In another terminal, simulate webhook (without signature for dev mode):
curl -X POST http://localhost:5000/api/payments/webhook/paychangu \
  -H "Content-Type: application/json" \
  -d '{
    "status": "success",
    "tx_ref": "TEST-123",
    "transaction_id": "TEST-123",
    "charge_id": "CHG-123",
    "amount": 1000,
    "currency": "MWK"
  }'
```

**Expected Response:**
```json
{
  "success": true,
  "payment": { ... }
}
```

### **STEP 4: Configure Production Webhook**

**Important:** You'll need to do this same process for **Production mode**:

1. In PayChangu dashboard, switch to **"Live Mode"** or **"Production Mode"**
2. Find the production webhook settings
3. Fill in **Production Webhook URL:**
   ```
   https://autotek.mw/api/payments/webhook/paychangu
   ```
4. Get/set the **Production Webhook Secret** (different from test!)
5. Enable notifications
6. Save
7. Update your production `.env`:
   ```bash
   PAYCHANGU_WEBHOOK_SECRET=your_production_webhook_secret
   ```

## 🐛 Troubleshooting

### Webhook Not Received

**Check 1: URL Accessibility**
```bash
# Test if your webhook endpoint is reachable
curl http://localhost:5000/api/payments/webhook/paychangu

# Should return error (wrong method) but proves it's accessible:
# "Cannot GET /api/payments/webhook/paychangu"
```

**Check 2: ngrok for Local Testing**
If testing locally, PayChangu can't reach `localhost`. Use ngrok:
```bash
ngrok http 5000
# Use the https URL it gives you
```

**Check 3: Backend Logs**
```bash
# Check if webhook is being received
npm run dev

# You should see in logs:
# [PayChangu] Webhook received
```

### Signature Verification Failing

**Check 1: Correct Secret**
```bash
# Verify your .env has the webhook secret
grep PAYCHANGU_WEBHOOK_SECRET backend/.env

# Should show: PAYCHANGU_WEBHOOK_SECRET=whsec_...
```

**Check 2: Secret Matches Mode**
- Test mode needs test webhook secret
- Production mode needs production webhook secret
- They are different!

**Check 3: Restart Backend**
```bash
# After adding/changing webhook secret
cd backend
npm run dev
```

### Getting 401 Unauthorized

This means signature verification failed:
- Wrong webhook secret in .env
- Using test secret with production webhooks (or vice versa)
- PayChangu changed the secret

**Solution:** Get fresh webhook secret from dashboard

### PayChangu Retries

If your endpoint doesn't return 200:
- PayChangu retries 3 times
- 30-minute intervals between retries
- Check your endpoint is returning success properly

## 🔒 Security Notes

1. **Always Verify Signature in Production**
   - Never disable signature verification in production
   - Each webhook secret is unique to your merchant account

2. **Use HTTPS in Production**
   - PayChangu requires HTTPS for production webhooks
   - HTTP only works for local testing with ngrok

3. **Don't Expose Webhook Secret**
   - Never commit to git
   - Store in .env file
   - Keep separate test and production secrets

4. **Re-verify Payment**
   - After webhook, optionally re-query PayChangu API
   - Confirms payment status before providing value
   - Recommended in docs for critical transactions
